# Portafolio web | Benjamin Riquelme Sanchez

## Descripción
Portafolio personal para presentar los proyectos que he desarrollado durante mi primer semestre de Ingeniería Civil en Informática en la Universidad Católica de Temuco.
## Tecnologías usadas
- HTML5 (estructura semántica)
- CSS3 (diseño responsivo con Flexbox y Grid)
- Git y GitHub (control de versiones)
## Estructura del proyecto
```
Portafolio/
├── css/styles.css
├── index.html
└── README.md
```
## Cómo abrir el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir `index.html` con la extensión Live Server, o directamente en el navegador.

## Decisiones de diseño

Estructura:usé etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`) para que la página sea clara tanto para personas como para lectores de pantalla.

Diseño responsivo: apliqué el enfoque mobile first con tres puntos de quiebre: móvil (menos de 768 px), tablet (desde 768 px) y escritorio (desde 1024 px). Los trabajos pasan de 1 a 2 y luego a 3 columnas.

Colores: usé un azul oscuro como color principal con texto blanco o negro sobre fondos claros, para mantener un contraste alto y buena legibilidad.

Accesibilidad:
- Idioma declarado con `lang="es"`.
- Jerarquía de encabezados ordenada (h1, h2, h3).
- Texto alternativo (`alt`) en las imágenes.
- Todos los campos del formulario tienen su `label`.
- Foco visible al navegar con el teclado.
- Enlace "Saltar al contenido" para navegación con teclado.
